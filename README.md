**v2.1.8** (Windows x64)

- SHA-256: `c10e43a1c57c6b472ea5cb6b0a5ea291da95df9ca6592aa987a09b9bed69d755`
- Verificar: `certutil -hashfile NidoX-2.1.8-windows-x64.zip SHA256`

## Cómo usar

1. Descargá el ZIP.
2. Verificá el hash (opcional pero recomendado).
3. Extrae a una carpeta (ej. `C:\Apps\NidoX\`).
4. Doble clic en `NidoX.exe`.
5. Si Windows muestra "Aplicación no reconocida", clic en
   "Más información" → "Ejecutar de todas formas".

Más detalles: [Quickstart](https://giannirisieri-collab.github.io/nidox-web/quickstart.html)
